# Crosswall 2 Demo

[게임 바로 플레이하기](https://mingi1178.github.io/crosswall2-demo/)

원본 Unity WebGL 데모에서 플레이할 수 있는 Starter 10개 레벨을 HTML, CSS, JavaScript로 옮겼습니다. 레벨 데이터와 이미지는 프로젝트에 들어 있어 인터넷 연결 없이 플레이할 수 있습니다.

## 로컬 실행

프로젝트 폴더에서 `index.html`을 더블클릭하면 브라우저에서 바로 플레이할 수 있습니다.

macOS에서 로컬 서버로 실행하려면 Python 3가 설치된 상태에서 `Crosswall.command`를 더블클릭하세요. 터미널 창에서 Control+C를 누르면 종료됩니다.

고정 주소를 쓰려면 프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

[웹판 플레이](http://127.0.0.1:4173/) · [원본 Unity 빌드와 비교](http://127.0.0.1:4173/original.html)

## 플레이

플레이 → Starter → 레벨 번호를 선택하세요. 파란색이 플레이어이고 빨간색이 컴퓨터입니다. 빈칸을 클릭하거나 탭하면 기존 벽이나 판 가장자리에 닿을 때까지 상하좌우로 벽을 놓습니다. × 칸에서 시작할 수 없지만 다른 칸에서 시작한 벽은 × 칸을 통과합니다. 마지막으로 벽을 놓은 쪽이 이깁니다.

전구는 상대가 최선으로 두어도 이길 수 있는 모든 칸을 노란색으로 표시합니다. 이전·다음 버튼은 플레이어의 수와 컴퓨터의 응수를 함께 되감거나 재생합니다. 되돌린 위치에서 새 수를 두면 그 뒤의 기록을 대체합니다.

## 9×9 · 19×19 필승 도전

플레이에서 **9×9 필승 도전** 또는 **19×19 필승 도전**을 선택합니다. 사람이 항상 파란색으로 먼저 둡니다. 빗금 친 구멍은 선택할 수 없고 십자 벽의 진행도 막습니다. 회전 화살표는 같은 판을 다시 시작하고, **새 랜덤판**은 같은 크기로 구멍을 새로 배치합니다. 19×19에서는 **판 확대**를 누르고 손가락으로 판을 밀어 원하는 칸을 찾을 수 있습니다. **전체 보기**를 누르면 361칸을 한눈에 볼 수 있습니다.

**힌트**를 누르면 현재 차례의 필승 수가 모두 노란 테두리로 표시됩니다. 필승 수가 없는 차례에는 컴퓨터의 전체 응수 중 필승 응수가 차지하는 비율이 가장 낮은 칸 하나를 보여줍니다. 다시 누르면 표시를 끕니다.

판 생성기는 전체 칸을 섞고 빈칸을 하나씩 열면서 일반 모드의 연결 영역을 최대 16칸으로 제한합니다. 9×9의 목표 빈칸 수는 48~56개, 19×19는 216~252개 사이에서 무작위로 고릅니다. 영역 크기 제한과 선공 필승 보정으로 실제 시작 빈칸 수는 목표보다 적을 수 있습니다. 각 영역에서 남은 칸을 비트마스크로 기록하고, 벽 때문에 영역이 더 쪼개지면 각 조각의 그런디 값을 XOR합니다. 게임 전체의 수순 트리를 만드는 대신 개별 영역에서 실제로 방문한 마스크만 계산해 값을 저장합니다. 캐시는 방문한 상태를 키로 사용하는 Map입니다.

모드 선택 화면의 **연결 영역**에서 기본, **30~32칸**, **40~42칸**, **50~52칸**을 선택할 수 있습니다. 9×9와 19×19 모두 큰 영역 하나를 상하좌우로 이웃한 빈칸을 무작위로 붙여 만들고, 구멍으로 경계를 둘러쌉니다. 다른 영역은 각각 최대 16칸입니다. 큰 영역 자체가 목표 빈칸 수보다 크면 선택한 영역 크기를 우선합니다. 시작 화면에 가장 큰 영역의 실제 칸 수가 표시됩니다.

19×19에서 **50~52칸 × 3 (19×19)**을 선택하면 각각 50~52칸인 독립 영역 세 개가 생깁니다. 세 곳에서 이웃 칸을 번갈아 붙여 불규칙한 모양을 만들고, 다른 영역과 닿는 칸은 비워 둡니다. 모든 행과 열에 플레이 가능한 칸이 한 개 이상 있는 배치만 사용합니다. 나머지 연결 영역은 각각 최대 16칸입니다. 게임 시작 시 큰 영역 세 개의 실제 크기를 표시합니다.

32칸까지는 32비트 마스크를, 그보다 큰 영역에는 BigInt 마스크를 사용합니다. 40칸 이상 옵션은 Web Worker에서 판 생성과 첫 필승 수 계산을 진행하고, 대국과 재시작에 그 영역의 그런디 값 캐시를 재사용합니다.

시작 판에는 항상 플레이어의 필승 수가 있습니다. 일반 모드는 생성 시 전체 그런디 값의 XOR가 0이면 합법적인 십자 벽 하나를 골라 그 자리를 구멍으로 바꿉니다. XOR가 0인 판에서 한 수를 두면 값이 반드시 0이 아닌 판이 되므로, 플레이어에게는 다시 0을 만드는 첫 수가 생깁니다. 큰 영역 옵션에서는 보정이 필요할 때 미리 분리해 둔 모서리 한 칸을 엽니다. 독립된 1칸 영역의 값이 1이므로 큰 영역을 그대로 두고 전체 XOR를 0에서 1로 바꿀 수 있습니다. 매 차례 필승 수를 선택하면 컴퓨터가 어떻게 응수해도 플레이어가 마지막 수를 둡니다.

### 스마트폰에서 열기

Mac과 스마트폰을 같은 Wi-Fi에 연결하고, 프로젝트 폴더에서 다음 명령으로 서버를 실행하세요. 휴대폰 브라우저 주소창에 `http://맥의-Wi-Fi-IP:4174/`를 입력합니다. Mac의 IP 주소는 시스템 설정 → Wi-Fi → 연결된 네트워크의 세부사항에서 확인할 수 있습니다.

```sh
python3 -m http.server 4174 --bind 0.0.0.0
```

## 소스와 복원 근거

게임 코드나 레벨 데이터를 수정한 뒤에는 `npm ci`와 `npm run build`를 실행하세요. 생성된 `web/game.bundle.js`도 함께 커밋하면 로컬 파일과 GitHub Pages 양쪽에 반영됩니다.

- `web/levels.json`에 원본 레벨 순서, 보드 크기, 금지 칸 좌표를 저장했습니다. 좌표 원점은 왼쪽 아래입니다.
- `web/rules.mjs`가 착수, 영역 분할, 컴퓨터와 힌트의 수를 계산합니다. 십자 벽이 나눈 각 직사각형의 그런디 수를 메모이제이션하고 XOR로 합칩니다.
- `web/holes.mjs`는 9×9와 19×19 랜덤판 생성, 구멍에서 멈추는 십자 벽, 연결 영역별 필승 수 계산을 구현합니다.
- `web/app.js`가 턴, 승패, 복기, 화면 전환을 관리합니다. `web/style.css`에서 세로 화면 비율과 컨트롤 배치를 수정할 수 있습니다.
- `tools/extract.py`는 Build.data 안의 Unity 번들에서 Starter 목록이 참조하는 레벨과 사용한 스프라이트를 다시 추출합니다. 재추출이 필요할 때만 별도 Python 가상환경에 `UnityPy==1.25.4`를 설치하고 `python tools/extract.py`를 실행하세요. 이 명령은 추출된 JSON과 PNG를 덮어씁니다.

Unity 2022.3.24f1 배포본의 장면과 직렬화된 데이터를 조사하고 실제 플레이를 대조했습니다. 규칙과 화면 로직은 새로 작성했습니다. 웹판에서는 같은 가치의 후보 중 컴퓨터가 무작위로 응수하며, 차례와 승패를 한국어로도 표시합니다.

기준 버전은 [crosswall-demo 커밋 62124cc](https://github.com/mingi1178/crosswall-demo/tree/62124cc6b2b7e8f56c945a3a587f9704a194f80d)입니다. [원본 공개 데모](https://mingi1178.github.io/crosswall-demo/)

## 검증

Node.js 18 이상에서 `node --test tests/*.test.mjs`를 실행하세요. 원본 게임 화면에서 읽은 첫 수 힌트를 10개 레벨별로 대조하고, 금지 칸과 기존 벽의 동작을 확인합니다.

9×9 모드의 테스트는 작은 비정형 판의 독립 완전탐색 결과와 비교합니다. 또한 고정 시드 250개의 모든 첫 수 힌트와 그에 대한 컴퓨터의 모든 첫 응수를 확인하고, 각 판을 끝까지 진행해 힌트를 따른 플레이어의 승리를 검증합니다.
